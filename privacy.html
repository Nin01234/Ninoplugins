Privacy Policy

Last updated: October 10, 2026

This page describes the NinoAI project's currently stated data practices. It does not replace the policies of ChatGPT, GitHub, or other platforms you use.

Request processing

NinoAI is described as using ChatGPT for request processing and providing plugin instructions and skills. No separate data-storage system is configured as part of the current project setup.

This does not mean third-party platforms never process or retain information. Information you submit may be handled under the relevant provider's systems, settings, and policies.

Information you provide

Only provide information needed for your task. Avoid submitting passwords, API keys, payment details, confidential work material, or sensitive personal information in prompts or public support issues.

Third-party services

This website links to external services, including GitHub. Those services have their own privacy practices. The statement that no separate NinoAI storage is configured refers only to the current project setup.

Changes and questions

Update this policy if the project adds analytics, a database, information collection, or other processing. For questions, visit GitHub Issues. Do not post sensitive information publicly.

This is a general project notice, not legal advice. Review it against your actual deployment before launch.
